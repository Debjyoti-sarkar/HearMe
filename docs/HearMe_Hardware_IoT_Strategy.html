1. Strategic Framing

Women's safety hardware in India fails on three common axes: too ugly to wear, too obvious to an attacker, or too expensive for the mass market. The HearMe hardware stack is built around three price tiers, each solving a different job. The HearMe app becomes the universal backend they all talk to.

TierPrice BandAudienceJob To Be Done
T1 Budget₹300 – ₹700Mass market, NGOs, rural"A panic button I can carry in my pocket."
T2 Fashion₹800 – ₹3,000Urban working women, students"Safety I'll actually wear daily."
T3 Specialist₹3,000 – ₹15,000Travel, journalists, field workers"Protection in genuinely high-risk zones."
Architectural principle: Build only the BLE protocol and the Tier-1 reference device in-house. Every other SKU is an OEM/co-brand partnership. The phone is the source of truth; hardware is the trigger.

11. Reference Technical Architecture

[ Hardware Devices ] -> [ Edge Protocols ] -> [ HearMe App ] -> [ Cloud ] BLE Button BLE GATT + PSK pairing Expo BLE plugin Supabase LoRa Beacon LoRaWAN -> MQTT (react-native-ble-plx) + Hash-Chain NB-IoT Tracker CoAP / LwM2M Companion device mgr Anchor Wearable (Watch) BLE + OTA DFU Webhook consumer Evidence Vault Smart Home Matter / Zigbee -> MQTT

Security Posture (non-negotiable)

  • All devices use pre-shared-key + ECDH pairing. No "enter 000000" weak PINs.
  • Firmware OTA signed with HearMe ed25519 key.
  • Every GATT write carries a replay-protected monotonic counter.
  • Devices store nothing identifying — the phone is the only source of truth.
  • Cloud-side hash-chain anchoring ensures evidence is court-admissible.

13. Recommended First Hardware Ship

The HearMe Clip — ₹499

A single SKU: a BLE panic keychain with pin and magnetic back so it can clip inside a bag, on a bra strap, on a keyring, or on a school ID lanyard. Runs on a CR2032 cell for a year.

Why this one device first:

  • Hits the Tier-1 mass market price point.
  • Lets you validate the BLE pairing UX inside the existing HearMe app.
  • Becomes the reference device every future partner SKU must interoperate with.
  • Easy to bundle into NGO and university CSR grants.

Everything else — jewellery, watches, helmets, dashcams — stacks on top once this protocol is stable in production.
